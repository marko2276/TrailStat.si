# TrailStat.si

A hiking and trail management application that helps users track personal and group hiking statistics, maintain lists of trails, and monitor completed routes. The platform supports group creation and optional sharing of activities and progress among members.

Available in English and Slovenian. Runs on PC, iOS and Android as an installable web app.
